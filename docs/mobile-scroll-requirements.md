# スマホの横揺れ修正

対象は https://www.talentkeeper.jp/ のLP。スマホ縦スクロール時の横揺れ報告に対応する。

## 要件

- 320 / 375 / 390 / 430px の画面幅で、初期表示・STORY表示途中・フッターでページの横幅が画面幅を超えない。
- 1024px未満では左右から表示される要素をフェードのみとする。デスクトップの左右演出は維持する。
- STORYの変形がページ外へスクロール領域を拡張しない。
- 小幅画面のフッターはリンクを折り返して全リンクを読めるようにする。
- 比較表内部の横スクロール、メニュー開閉、固定ナビゲーションを維持する。
- 768 / 1024 / 1440pxでも横幅とフッター・固定ナビを回帰検証する。

## 原因・設計

公開サイトで375 / 390 / 430px時に16pxのはみ出しを確認。STORYは左右余白24pxに対し40px移動する。透明な未表示要素もスクロール領域に含まれる。
320pxではフッターの折り返しなしリンク列も約11pxはみ出す。

比較した方針: ページ全体をoverflow hiddenで隠す／タッチ方向を制限する／演出元とリンク列の寸法を修正する。
原因箇所を修正する方式を採用。CSSメディアクエリで表示演出を切り替え、STORYをoverflow-x: clipとする。
全体のoverflow hiddenはstickyへの副作用があり、touch-actionでの制限は比較表と拡大操作への影響があるため採用しない。

## 検証

Playwrightで初期・スクロール中の実測寸法、リンクの矩形、ナビの固定位置、表のscrollLeft、メニューの可視性を確認する。
ChromiumとWebKitを使用する。iOS実機の端の跳ね返りを完全再現したという主張はしない。
実行: npm ci --legacy-peer-deps → npx playwright install --with-deps chromium webkit → npm run build → npm run test:layout。
