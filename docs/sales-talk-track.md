# 商談トークスクリプト（社外非公開）

「こんなケースありませんか？」→ 近い事例を選ぶ → 「実はこういう事例があって…」の流れで使う想定。
各事例の詳細は記事URLをその場で開くか、記事ページをブラウザの「PDFで保存」で印刷して配布する。

> このファイルは content/voices/*.md の salesTalk から自動生成されます（編集しないでください）。
> 生成コマンド: npm run voices

## CASE 01｜新入社員の勤務不安

- 従業員の声：「自分だけ勤務の仕方が違う。このままで大丈夫だろうか」
- 記事URL：https://www.talentkeeper.jp/voices/shinnyushain-kinmu-fuan/
- 課題喚起：新人の方が、周りと違うシフトや教育の進み方に不安を持っていても、人事まで上がってこないことはありませんか？
- 現状確認：今は入社後の不安を、誰が・どのタイミングで拾っていますか？
- 事例への接続：実際に、勤務体制・業務習得・人間関係の3つが重なって不安になっていた新人の相談事例があります。
